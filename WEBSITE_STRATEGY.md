# DJ Too Kold Website Strategy

## Goal

Build a fast, polished booking website that turns visitors into event inquiries.

## Primary Audience

People planning weddings, private parties, school events, corporate events, clubs, and celebrations who need a reliable DJ with strong crowd control and clean event flow.

## Conversion Path

1. Land on a clear hero that immediately communicates the brand and energy.
2. Understand the main event types and performance style.
3. Move into `booking.html` with enough confidence to share event details.
4. Use `contact.html` for lighter questions, collaborations, or follow-up.

## Current Site Structure

- `index.html`: brand impact, services, and main call to action.
- `about.html`: approach, preparation, performance style, and follow-through.
- `booking.html`: event inquiry form and booking expectations.
- `contact.html`: general message form.

## Efficient Build Plan

### Phase 1: Foundation

- Keep the site static for speed and simple hosting.
- Use shared CSS and shared form JavaScript.
- Keep copy focused on event outcomes, not generic web language.
- Make every core page mobile responsive.

### Phase 2: Booking System

- Connect forms to Netlify Forms, Formspree, or a custom endpoint.
- Replace `info@tookoldweb.com` in `script.js` with the real public booking email.
- Add required booking fields only after confirming what DJ Too Kold needs to quote accurately.

### Phase 3: Trust Builders

- Add event photos or short performance clips.
- Add testimonials.
- Add a simple package or event-type comparison section.
- Add social links and embedded music/video proof if available.

### Phase 4: Launch Polish

- Add real SEO titles and descriptions for every page.
- Add Open Graph preview metadata.
- Add favicon and social preview image.
- Run accessibility, mobile layout, and form-submission checks.

## Design Direction

The visual style should feel energetic and professional: dark event imagery, cyan lighting, warm accent contrast, sharp typography, and simple conversion-focused layouts.

Avoid turning the site into a generic agency page. DJ Too Kold should be the first signal on the site, and booking should always be easy to reach.
