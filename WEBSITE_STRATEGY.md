# DJ Too Kold Website Strategy

## Goal

Build a fast, polished booking website that turns visitors into event inquiries for DJ Too Kold.

## Primary Audience

People planning weddings, private parties, proms, school events, corporate events, nightlife, and social celebrations who need a reliable DJ with strong crowd control and clean event flow.

## Conversion Path

1. Land on a clear hero that immediately communicates DJ Too Kold, the event categories, and the booking action.
2. Understand the main services, event types, and performance style.
3. Preview the brand feel through mixes, gallery visuals, testimonials, and FAQs.
4. Move into `booking.html` with enough confidence to share event details.
5. Use `contact.html` for lighter questions, collaborations, or follow-up.

## Site Structure

- `index.html`: brand impact, services, event types, mixes preview, testimonials, and main booking CTA.
- `about.html`: approach, preparation, performance style, and follow-through.
- `services.html`: event service cards and planning details.
- `booking.html`: event inquiry form and booking expectations.
- `mixes.html`: audio-embed-ready mix showcase.
- `gallery.html`: responsive photo gallery grid.
- `events.html`: event categories and flow.
- `contact.html`: general message form.
- `faq.html`: common booking questions.

## Build Notes

- Keep the site static for speed and simple hosting.
- Use shared CSS and shared form JavaScript.
- Keep copy focused on event outcomes, not generic web language.
- Make every core page mobile responsive.
- Keep booking visible in navigation, page CTAs, and footer navigation.

## Booking System

- Connect forms to Netlify Forms, Formspree, or a custom endpoint.
- Replace `info@tookoldweb.com` in `script.js` with the real public booking email.
- Add required booking fields only after confirming what DJ Too Kold needs to quote accurately.

## Trust Builders

- Add real event photos or short performance clips as they become available.
- Replace placeholder testimonials with approved client quotes.
- Replace mix placeholders with SoundCloud, Mixcloud, Spotify, YouTube, or native audio embeds.
- Add social links once official public profiles are confirmed.

## Launch Polish

- Add a favicon and social preview image.
- Add real Open Graph preview metadata.
- Run accessibility, mobile layout, and form-submission checks.
- Confirm the public booking email and any social links before launch.

## Design Direction

The visual style should feel clean, icy, high-energy, premium, and conversion-focused: full-bleed event imagery, confident typography, blue-white accents, restrained dark bands, and simple layouts that keep booking easy.

Avoid turning the site into a generic agency page. DJ Too Kold should be the first signal on the site, and booking should always be easy to reach.
