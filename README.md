# DJ Too Kold Website

A fast static booking website for DJ Too Kold.

## Pages

- `index.html`: homepage and main booking call to action
- `about.html`: event style and approach
- `booking.html`: booking request form
- `contact.html`: general contact form

## Notes

The forms are ready for Netlify Forms or a custom endpoint. Update `publicEmail` in `script.js` with the real booking email before launch.
